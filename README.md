# DecorMatrix — Official Landing Page 🚀

The official, high-conversion landing page and interactive showcase for **DecorMatrix** — India's leading modular kitchen quotation software for manufacturers, interior designers, contractors, and retailers.

Live URL: [https://decormatrix.vercel.app](https://decormatrix.vercel.app)

---

## ✨ Features Highlighted

- **Interactive Live Estimator**: Instant Running Feet (RFT) and material cost calculator.
- **5-Step Visual Workflow**:
  1. Choose Kitchen Layout (Straight, L-Shape, U-Shape)
  2. Input Kitchen Dimensions (Wall A, Wall B in Ft + In with Auto Corner Cut)
  3. Pick Material & Package Tiers (PVC vs Marine Plywood, Essential/Premium/Luxury)
  4. Customize Cabinets & Accessories
  5. Generate Instant Branded PDF & 1-Click WhatsApp Share
- **100% Free Lifetime Access**: No subscription fees, no credit card, unlimited quotations for all users.
- **Full SEO & Schema Markup**: JSON-LD Structured Data, Canonical tags, OpenGraph previews, `robots.txt`, and `sitemap.xml`.
- **100% Responsive Design**: Zero horizontal overflow, custom mobile frames, and high-performance CSS.

---

## 🛠️ Tech Stack

- **Framework**: Pure HTML5 & Vanilla JavaScript
- **Styling**: Vanilla CSS (Tailored Design System, Crimson Theme `#e11d48`)
- **Bundler**: Vite
- **Deployment**: Vercel ready (`vercel.json`)

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/YASH2221/decormatrix-landing.git

# Navigate to project directory
cd decormatrix-landing

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
